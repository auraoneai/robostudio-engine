# Security Policy

Report suspected vulnerabilities privately to `security@auraone.ai`.

Do not include private robot media, credentials, access tokens, customer data,
operator data, absolute dataset paths, or proprietary dataset metadata in a
public issue. Provide the affected command, package version, operating system,
and the smallest sanitized reproduction that demonstrates the problem.

`robostudio-engine` is an alpha local tooling package. Dataset QA findings,
redaction helpers, and export checks are review aids and are not security or
safety certification.
